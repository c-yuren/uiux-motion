# Existing Design Awareness
Before touching existing work, locate requested surface and source assets, inspect current render/behavior, existing tokens/styles, component boundaries, architecture, dependencies, relevant states, tests, git status and user locks. Record baseline proportional to scope; screenshots/recordings when possible. Distinguish intentional choices from defects; if unclear preserve them. Prefer existing dependencies and conventions. Do not replace identity, architecture or shared components merely for novelty.
Check downstream consumers, shared tokens, responsive variants, inputs, locales, async states and previous approvals. Determine smallest safe ownership scope. Keep unrelated edits intact; if concurrent conflict, stop that path and reconcile. If baseline cannot be observed, record limitation and avoid claiming improvement. Use .uiux registry for full/batch audit; do not force it for a trivial edit. Choose exact intent: [extend](extend.md), [adjust](adjust.md), [refine](refine.md), [redesign](redesign.md), [repair](repair.md), [migrate](../shared/migrate.md).
