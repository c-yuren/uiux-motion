# Produce stage
Implement only authorized scope and approved/ready decisions as applicable. Read contract or actual user design specification; if insufficient for a consequential choice, return to Design or ask. For small direct adjustments the user instruction is the specification. Inspect existing framework, components, tokens and dependencies; use native/existing tools first. Implement real editable deliverable and code, preserve business state, responsiveness, accessibility, reduced motion, asset licenses, cleanups. Keep prototype separate unless explicitly integrating. Use current design geometry and intent, not pixel imitation at expense of semantics. Record deviations and test, return to Design for significant changes. Review changed files, run relevant functional/visual/performance/regression tests; use actual evidence. No deployment/push without user authorization. Produce-only never automatically approves redesign.
