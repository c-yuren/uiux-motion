# Usage, input and medium
High-frequency productivity: minimize latency, repeated decoration and unnecessary actions; preserve working context. Monitoring: stable geometry, concise state cues, live update semantics. Browsing/discovery: hierarchy, navigation, scanning and interruption recovery. Long reading: typography, focus, zoom and restrained motion. Presentation: narrative, purposeful effects and accessible still alternative. Input can be mouse, keyboard, touch, stylus, assistive or unknown; support actual intended inputs and baseline accessibility; do not infer abilities from device. Medium may be interactive-ui, html, svg, pdf, print, slides, image, video or unknown. Medium determines output fidelity, not product purpose. Use host output tooling for requested formats. Explicit user locks and functional/accessibility requirements win over contextual preferences.
