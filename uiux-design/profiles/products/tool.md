# Tool / productivity
Examples: IDE, CAD, editor, file manager, AI agent manager, SaaS admin. Optimize task completion, discoverability, predictable commands and precision. Favor semantic grouping, controlled density, persistent working context, selection, shortcuts when available, clear error recovery and undo. Use restrained, fast feedback and no distracting ambient effects in work areas. Complex tools may use panels, trees and tables; don't force large marketing cards. Test repeated actions, search, long labels, selection/keyboard, unsaved states and narrow windows. On mobile adapt for touch, not miniature desktop panels.
