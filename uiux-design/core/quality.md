# Shared quality and validation
Mandatory gates depend on dimension: function/meaning, visual rendering, accessibility, regression; information adds data accuracy; motion adds interruption and performance; interaction adds interruption and functional state. Apply other relevant gates even if not minimum. No scoring may offset a mandatory failure. Record pass/fail/unknown/na with reason and evidence paths; na only when truly inapplicable.
Visual: actual render at target sizes/themes; inspect alignment, hierarchy, spacing, text clipping, contrast, density, material, icon legibility and unintended overflow. Compare with baseline and design intent. Information: verify source values, units, denominators, scales, color semantics, missing data, uncertainty. Interaction: pointer/touch/keyboard, focus, rapid repeats, async/error, cancellation and state. Motion: actual sequences/recordings, interruption and frame-time/profile evidence, reduced motion and cleanup.
Use relevant WCAG guidance; contrast and color-independent cues, keyboard navigation and focus, text alternatives, reduced motion and pause/stop for persistent effects. Avoid decorative animation that competes with reading. Profile actual target environment; a rAF interval isn't a rendered frame rate. Do not assume one browser or emulated device proves native platform behavior.
Quality tiers Functional, Refined, Premium (default goal), Signature. Judge against context and actual evidence, not arbitrary numeric score. V0 none, V1 static, V2 functional tests, V3 visual renders/sequence, V4 complete relevant gates, V5 additional cross-device/human evidence. Scope and verification are independent. If missing tools, mark pending/blocked; if budget ends, preserve outstanding work.
